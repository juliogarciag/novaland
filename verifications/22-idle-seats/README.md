# Verifications for #22 - Free seats held by idle players

Ticket: https://github.com/juliogarciag/novaland/issues/22. Builds on #17 (the world room) and #18 (the client's online mode), both on `main`.

The server decides who is idle: the room measures every session's idle time on its own clock (`WorldRoomOptions.clock`, `performance.now` in production) from the last input that passed the edge gate, except while that input is a move with a direction (a held key: the client sends a move only when the direction changes, so walking is never idle), and `IDLE_TIMEOUT_MS` (10 minutes, `IDLE_TIMEOUT_SECONDS` in the environment for one boot, at least 1 s) after it frees the seat, sends `player/leave` to the sim and closes the session with WebSocket close code **4100** and reason **`idle`** (`IDLE_KICK` in `packages/server/src/world/kicks.ts`). The client side: on a close with 4100 the browser client shows an away screen (`data-screen="away"`, "You were away…", a focused Rejoin button) and does not reconnect by itself; every other close keeps the automatic reconnect. The client only reads the close code: the server alone decides who is idle. So the highest-level users are a Node client that joins by id and sees `onLeave(4100, 'idle')`, and a person with the game open in a browser tab.

Run everything (from anywhere; installs Playwright on first run):

```bash
bash verifications/22-idle-seats/run.sh
```

Each script prints `PASS`/`FAIL` lines, exits non-zero on failure, and writes its proof into `proof/`.
