# Verifications for #19 - One deployable process: serve the built client and the world room from one port

Ticket: https://github.com/juliogarciag/novaland/issues/19. Stacked on #18 (`18-client-online-mode`, PR #28), #17 (PR #27) and #16 (PR #24).

The highest-level user of this ticket is whoever deploys the game: they build one image, run it with a `PORT`, point a health check at `/health`, and two people open the URL and see each other move, with nothing else configured. So the proof is the real image, built and run with Docker, driven from the served URL by Playwright, with a Node observer of the authoritative world as the witness (production builds carry no debug API, so the pages cannot be asked).

Run everything (from anywhere; installs Playwright on first run; `03` needs Docker):

```bash
bash verifications/19-one-process/run.sh
```

Each script prints `PASS`/`FAIL` lines, exits non-zero on failure, and writes its proof into `proof/`.
