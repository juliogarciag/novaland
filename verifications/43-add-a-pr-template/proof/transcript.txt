Why: gh 2.36.0 asks GitHub for the repository's templates, and GitHub reads them from the default branch.

$ gh api graphql -f query='query($owner:String!,$name:String!){repository(owner:$owner,name:$name){pullRequestTemplates{filename}}}' -f owner=juliogarciag -f name=novaland
{"data":{"repository":{"pullRequestTemplates":[]}}}
The same question about a public repository whose main branch has a single .github/PULL_REQUEST_TEMPLATE.md:

$ gh api graphql -f query='query($owner:String!,$name:String!){repository(owner:$owner,name:$name){pullRequestTemplates{filename}}}' -f owner=vitejs -f name=vite
{"data":{"repository":{"pullRequestTemplates":[{"filename":"PULL_REQUEST_TEMPLATE.md"}]}}}
So gh can offer this template only once this PR is on main, and only in a terminal:
`gh pr create --body`, which is how agents open PRs, never reads it. AGENTS.md now tells them to.
